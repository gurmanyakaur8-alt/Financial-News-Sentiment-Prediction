# Financial News Sentiment Prediction using Deep Learning & FinBERT
 
## Objective
Classify finance-related tweets into:
- Bearish
- Bullish
- Neutral
 
## Dataset
Twitter Financial News Sentiment Dataset
 
## Models Used
- Simple RNN
- LSTM
- GRU
- FinBERT
 
## Evaluation Metrics
- Accuracy
- Macro F1 Score
- Precision
- Recall
 
## Technologies
- Python
- TensorFlow
- Hugging Face
- Streamlit
- NLP
